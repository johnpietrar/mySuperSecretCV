# 🚀 Quick Start Guide

Get your pixel CV running in 3 simple steps!

## Step 1: Install Dependencies
```bash
npm install
```
This will install all required packages (React, Vite, Tailwind, Framer Motion, etc.)

## Step 2: Start the Development Server
```bash
npm run dev
```
Your browser will automatically open to `http://localhost:3000`

## Step 3: Explore & Have Fun! 🎮

### Try These First:
1. **Click the ghosts** as they float by
2. **Click Pedro** (the dancing raccoon in the bottom right)
3. **Click the yellow button** on the gamepad (bottom left)
4. **Enter the Konami Code**: Press ⬆️⬆️⬇️⬇️⬅️➡️⬅️➡️BA on your keyboard

## Building for Production

When you're ready to deploy:

```bash
npm run build
```

This creates an optimized build in the `dist/` folder that you can deploy anywhere!
